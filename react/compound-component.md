# Compound component
- je to návrhový vzor, kdy se skupina komponent navrhne tak, aby spolupracovaly a sdílely vnitřní stav
- používá se například u tabů, ne všechny mají dropdown a v UI si to přímo vyskládám tak, jak potřebuji
- sdílený stav se řeší většinou pomocí context API
- výhodou je flexibilita layoutu, čitelnost a zapouzdřený stav (stav se řeší uvnitř komponent, navenek není vidět)
